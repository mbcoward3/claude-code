# plan-ui

When you're about to present a plan, approach, or design the user will review
before you implement, collaborate on it with plan-ui instead of prose.

Run `plan-ui playbook` and follow it — the playbook has the full loop and the
authoring rules. If `plan-ui` isn't on `PATH`, run the bundled `bootstrap.sh`
once to install it first.
